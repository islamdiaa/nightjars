# Nightjars: 2,194 Days · Demo

A Second World War stealth-tactics game told as a playable documentary. This is the public demo:
the first five missions (September 1939 to April 1940) in the 3D world. The rest of the campaign is
coming soon.

Play it at **https://itayar.com/nightjars**.

This repository holds the built demo only, published to GitHub Pages. Archive photographs and music
are public domain or Creative Commons and are credited in the game (Credits & sources).
